# loomi documentation

> loomi is a minimalistic Python Object-Graph Mapper for **Neo4j** and **Memgraph**. You can use it as a drop-in replacement for drivers from the [`neo4j` package](https://pypi.org/project/neo4j/).

## How to use these docs

Choose the section that best fits what you are working on:

| Section                                                | Goal                                                      |
| :----------------------------------------------------- | :-------------------------------------------------------- |
| **[Getting started](./getting-started.md)**            | Set up a first Loomi example                              |
| **[User guide](./user-guide/index.md)**                | Learn the core features and advanced APIs                 |
| **[Contributor guide](./contribution-guide/index.md)** | Set up development, run tests, and prepare a pull request |
