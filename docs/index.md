# loomi documentation

> loomi is a minimalistic Python Object-Graph Mapper for **Neo4j** and **Memgraph**, designed as a drop-in replacement for drivers from the [`neo4j` package](https://pypi.org/project/neo4j/).

## How to use these docs

The documentation is split into three main sections, grouped by how frequently you'll need them:

| Section                                                | Goal                                                                       |
| :----------------------------------------------------- | :------------------------------------------------------------------------- |
| **[Getting started](./getting-started.md)**            | Get up and running in under 5 minutes                                      |
| **[User guide](./user-guide/index.md)**                | Learn core functionality and advanced APIs                                 |
| **[Contributor guide](./contribution-guide/index.md)** | Learn how to set up a dev environment, run tests, and submit pull requests |
