# Welcome to the `loomi` documentation

> **loomi** is a minimalistic Python Object-Graph Mapper for **Neo4j** or **Memgraph** designed to be a drop-in replacement for drivers from the [`neo4j package`](https://pypi.org/project/neo4j/).

---
