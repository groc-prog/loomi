# Contributing to loomi

First of all, thank you for your interest in contributing to **loomi**!

Whether you are fixing a bug, improving documentation, adding a feature, or reporting an issue, every contribution is welcome and appreciated.

---

## How would you like to contribute?


| I want to...              | Action                                                                                  |
| :------------------------ | :-------------------------------------------------------------------------------------- |
| **Report a bug**          | Check [existing issues](https://github.com/groc-prog/loomi/issues) or open a new issue. |
| **Suggest a feature**     | Open a new [feature request](https://github.com/groc-prog/loomi/issues/new).            |
| **Improve documentation** | Read the [documentation guide](./documentation-guide.md) and submit your fix.           |
| **Write code / Fix bugs** | Follow the [development setup](./dev-setup.md) to get up and running.                   |
