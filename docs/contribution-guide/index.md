# Contributing to loomi

Thanks for thinking about contributing to loomi. We are glad you are here.

You can help in lots of ways, from reporting an issue to improving the docs or fixing a bug. Choose the path that fits what you have in mind.

## How would you like to contribute?

| I want to...               | Action                                                                                                                                    |
| :------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| **Report a bug**           | Check [existing issues](https://github.com/groc-prog/loomi/issues), or [open a new issue](https://github.com/groc-prog/loomi/issues/new). |
| **Suggest a feature**      | Share your idea in a [feature request](https://github.com/groc-prog/loomi/issues/new).                                                    |
| **Improve documentation**  | Follow the [documentation guide](./documentation-guide.md) to make a change.                                                              |
| **Write code or fix bugs** | Set up your environment with the [development guide](./dev-setup.md).                                                                     |
